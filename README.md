# 一死重开 / Death Reset

适用于 **Minecraft 26.1.2 + Fabric** 的局域网联机模组。房主打开单人存档，选择「对局域网开放」后，任意玩家真正死亡都会触发 **10 秒倒计时**，随后自动更换随机种子、重建整个世界，并再次开放同一个联机端口。

## 安装和游玩

1. 安装 Minecraft 26.1.2、Fabric Loader 0.19.5 或更新版本、Fabric API 0.155.3+26.1.2 或适配 26.1.2 的更新版本；运行游戏需要 Java 25。
2. 将 `death-reset-1.0.0+26.1.2.jar` 放入**实际使用的游戏实例**的 `mods` 文件夹。启用版本隔离的 HMCL/PCL 实例应使用该版本自己的 `mods` 文件夹。
3. 房主与朋友都安装此模组，房主进入一个世界并「对局域网开放」，朋友照常加入。
4. 有人死亡后，所有在线玩家收到中文标题与倒计时。10 秒结束后，房主保存旧世界、生成新世界、自动进入新一局并重新开放原端口。客机自动尝试重新连接。

只有房主安装时，死亡倒计时和重置仍然生效；没安装模组的朋友需要在世界重新开放后手动加入。普通未对局域网开放的单人游戏不会触发重置。本版本针对局域网房主设计，不支持独立服务器或 Realms。

重置会短暂断开连接；新世界生成需要额外时间。安装模组的客机每 5 秒重试一次，最多等待 2 分钟，可以在等待界面或连接界面取消。**联机端口保持不变**：房主始终复用重置前的端口；若暂时被占用，会显示提示并持续重试原端口。客机等待超时后也可以手动连接原来的地址和端口。

## 右侧死亡榜
未死亡的玩家显示 0。每次真正死亡都会加 1，包括重置倒计时内发生的后续死亡。

排行榜在每次换种子重开后保留，退出游戏再进入同一存档也继续累计。不同存档分别统计；退出的玩家也保留在榜单上。统计按玩家 UUID 记录，改名不会清空次数。使用原版侧边栏同步，没安装模组的客机也能看到死亡榜；屏幕最多显示原版侧边栏支持的 15 行。

统计文件位于房主游戏实例下的 `config/deathreset/deaths/<存档目录名>.json`。如需从零重新统计，退出这个世界后，将对应统计文件改名移走。排行榜会占用原版的右侧计分板位置。

## 重置内容

- **重新开始：** 主世界、下界、末地及其他世界维度、建筑、物品、玩家背包、末影箱、经验、进度、统计、出生点与世界运行数据。即使开启 `keep_inventory`，下一局也会清空旧局背包。
- **保留设置：** 存档名称和目录、难度、难度锁定、极限模式、游戏模式、游戏规则、世界生成类型、结构与奖励箱设置、数据包、世界资源包，以及联机游戏模式和允许作弊选项。
- 每一局使用新随机种子，保证与上一局不同。超平坦世界仍然是超平坦，种子变化对其地形的影响由原版决定。
- 不死图腾救活不算死亡；其他模组取消的死亡也不会触发。倒计时中其他人再次死亡不会延长倒计时或重复重置。
- 只在房主进程启动倒计时，客机负责接收重置通知和重新连接，不会修改客机自己的存档。

## 旧世界备份和恢复

每次重开都会将旧世界**完整移入**房主当前游戏实例下的：

```text
death-reset-backups/<原存档目录>-<时间>-<随机编号>/
```

新一局继续使用原存档目录，因此退出游戏后，再打开该存档就是最新一局。备份不会自动删除，长期游玩可以在游戏关闭后整理旧备份。

若需要恢复某一局：先退出这个世界，将 `saves` 中当前同名存档移到其他位置保留，再把目标备份文件夹放回 `saves`，并改为原存档目录名。备份包含原来的地形、所有玩家数据和进度。

重建遇到可捕获的错误时，模组尝试自动恢复旧世界，并显示恢复结果；失败的新世界也会保留在 `death-reset-backups/failed-*`。无法自动恢复时，错误界面和日志会给出旧世界备份的位置。

## 构建与验证

```powershell
# JAVA_HOME 应指向 Java 25 JDK
.\gradlew.bat build
```

安装用 JAR 位于 `build/libs/`；带 `-sources` 的 JAR 是源码包。

JUnit 测试覆盖倒计时边界、重复死亡、卡顿后的倒计时、三维度和玩家进度备份、恢复、非法目录拒绝、连续重置，以及死亡统计持久化、改名与存档隔离。双客户端集成测试使用普通开发客户端，通过真实原版世界创建、Fabric LAN 连接和玩家死亡执行完整流程。

在两个终端运行以下命令即可复现联机集成测试。测试只使用项目 `build` 下的独立游戏目录。重跑前，将已有 `build/lan-test-sync` 文件夹改名移开，避免读到前次测试的通信文件。

```powershell
.\gradlew.bat runLanTestHost
.\gradlew.bat runLanTestGuest
```

测试场景包括客机死亡、房主死亡、连续两次重开、随机种子变化、原端口复用、双方背包/经验清空、旧建筑清空、游戏规则保留、死亡榜显示和累计次数保留，以及客机两次自动重连。通过标记位于 `build/lan-test-sync/host-passed.txt` 与 `guest-passed.txt`。重跑时也应将之前的 `build/lan-test-host`、`build/lan-test-guest` 目录改名移开，以使用全新的独立测试实例。
